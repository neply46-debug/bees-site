# Пчёлки 🐝

Интерактивный сайт-опросник про пчёлок. Написан на чистых HTML, CSS и JavaScript.

## 🔗 Демо

После публикации сайт будет доступен по адресу:
`https://ТВОЙ_НИКНЕЙМ.github.io/bees-site/`

## 🚀 Как задеплоить через GitHub Pages

1. Создай новый репозиторий на GitHub, например `bees-site`.
2. Загрузи в него файлы `index.html`, `style.css`, `script.js` и `README.md`.
3. Зайди в **Settings → Pages**.
4. В разделе **Source** выбери **Deploy from a branch**.
5. Выбери ветку **main** и папку **/ (root)**, нажми **Save**.
6. Подожди 1–2 минуты — сайт будет доступен по ссылке выше.

## 🎮 Как это работает

| Что вводишь | Что происходит |
|---|---|
| `я уважаю пчелок` | «правильный ответ!» + добрая пчёлка 🐝 (прыгает) |
| `я не уважаю пчелок` | «мы знаем где ты живешь» + злая пчёлка 🐝 (дрожит) |
| Любой другой текст | «попробуй ещё раз 🤔» |
